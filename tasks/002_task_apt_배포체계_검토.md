# 002 apt 배포체계 검토
목표: 전 장치 신규 OS(Debian) 적용 + apt 지속 패치 + SBOM 제출 체계 요구사항·구상 확정
상태: 진행중

## 사실 (확인된 것만)
- 대상: E3-DP, E3-RDP, E3-HDLC(NanoPi H3 armhf, Ubuntu 16.04), E3-GW(Raspberry Pi, Raspbian 8). 수십 대.
- KT SBOM 가이드: 제품 단위 제출, CycloneDX 1.4/1.5 또는 SPDX 2.2/2.3 JSON, purl·직접/전이 의존성 필수, 취약점 조치 시 재제출.
- 이번 범위: 신규 OS 적용 + 업그레이드 시스템. 앱 보안(프로토콜 암호화 등)은 제외, 추후 별도 검토.
- U-Boot 갱신은 제외.
- 업그레이드: 서버가 장치에 신호 전송 → 장치(`e3-updater` 가칭)가 로컬에서 apt 실행. 1단계 수동, 2단계 자동.
- 현장 전환: microSD 일괄 이미지 교체.
- 요구사항은 최소 요건만 유지(사내 검토에서 사용자가 정의). 기능 요구 28개(F-01~F-28), 비기능 5개(N-01~N-05). 인수 기준은 §8 체크리스트에 통합. 자동 모드·VEX·장치별 조회·선별 미러링은 후속/필요 시.
- 배포 서버 방침: 개발자 개입 최소, Debian 표준 미러링·저장소 도구(aptly) 설정만 사용. USB 번들 방식 대신 외부 스테이징 서버에서 미러링·서명·보안 검사 후 검사 완료 서버(저장소) 단위로 반입. 폐쇄망 서버는 읽기 전용, 서명 키 미보유. 요구사항 문서 반영 완료.
- Raspberry Pi OS는 Debian 13 Trixie 기반 32bit 이미지 제공(웹 검색 확인).
- DP용 Debian 13 PoC 이미지: 생성·정적 검증 완료, 실장비 부팅 미시험.
